# Lunarune

**Windows で RuneLite を起動し、プロフィール用フォルダーを確認するためのビジュアルコンパニオンです。**

**言語:** [Português](README.md) · [English](README.en.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

## ダウンロード

- [最新の Lunarune.exe をダウンロード](https://github.com/SadRivensz/Lunarune/releases/latest/download/Lunarune.exe)
- [全バージョンと更新内容を見る](https://github.com/SadRivensz/Lunarune/releases)

公開されている実行ファイルは Windows x64 用で、必要な .NET ランタイムを含みます。.NET SDK のインストールは不要です。Lunarune はポータブルアプリです。ファイルをダウンロードして起動してください。インストーラーはありません。必要であれば、デスクトップやスタートメニューにショートカットを作成できます。

アプリにはまだデジタル署名がないため、Windows がセキュリティ警告を表示する場合があります。実行前に、プロジェクトの公式 Releases ページからダウンロードしたファイルであることを確認してください。

## 初回設定

1. Lunarune を起動します。
2. **RuneLite.exe の場所...** をクリックし、PC にインストールされている RuneLite の実行ファイルを選択します。
3. **credentials フォルダーの場所...** をクリックし、プロフィール用フォルダーが入っているフォルダーを選択します。
4. ウィンドウ上部のセレクターから言語を選びます。

一覧には選択したフォルダー直下のサブフォルダーが表示されます。何も表示されない場合は、選択した場所を確認してください。フォルダーボタンを押すと、選択した場所がエクスプローラーで開きます。

## RuneLite の起動

**別のインスタンスを開く**を押すと、選択した RuneLite を起動し、Lunarune の画面は開いたままになります。一覧のプロフィールを選択しても、ハイライト表示されるだけです。アカウントの切り替えや自動ログインは行いません。認証は RuneLite とその公式の方法で行ってください。

## プライバシーとローカルデータ

Lunarune は認証ファイルの内容を読み取らず、認証情報をコピー・変更しません。パスワード、トークン、アカウント名、選択したプロフィールも保存しません。

ローカルに保存する設定は、選択した RuneLite とプロフィールフォルダーのパス、および言語だけです。保存先は次のとおりです。

**%LOCALAPPDATA%\\Lunarune\\settings.json**

サブフォルダー名はアプリの実行中に一覧へ表示されますが、設定には保存されません。アプリはこれらのデータをインターネットへ送信しません。credentials フォルダーはPC内に保管してください。**GitHub にアップロードしたり、認証ファイルを共有したりしないでください。**

## 言語

ポルトガル語、英語、スペイン語、フランス語、ドイツ語、日本語に対応しています。選択した言語は他のローカル設定と一緒に保存されます。

## アップデート

利用できるバージョンは[Releases ページ](https://github.com/SadRivensz/Lunarune/releases)で確認できます。更新するには最新の実行ファイルをダウンロードしてください。設定はアプリ本体とは別に保存されます。
